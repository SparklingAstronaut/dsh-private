# 连续故事 / 连环画规划

把用户在 `/story` 后面写的故事（可以很短）变成一套能在图片工作台里一格一格画出来、角色保持一致的方案。只做规划和提示词，不要自己调用出图，除非用户明确说"直接画"。

## 先判断用哪条路线

- **千问路线（默认，角色最稳）**：真人、写实、半写实、或用户没指定风格时用。依靠 Qwen-Image 2.1 的多参考图：先画一张角色设定图，之后每一格都勾选这张设定图当参考。
- **Anima 路线**：用户明确要二次元/日系动漫画风时用。Anima 没有锁脸工具，靠"每格完全相同的角色标签 + 相同画师 + 相同 LoRA"保持一致，长相会有小差异，要提前告诉用户。

## 必须遵守的连续性规则

1. **角色设定只写一次，之后逐字复用**：发色、发型、瞳色、脸型特征、身高体型、固定服装（颜色+款式+配饰）。每一格的提示词里都原样带上这段，不要换说法。
2. **每格都参考同一张角色设定图**，不要拿上一格当参考（误差会一格一格累积）。场景需要连续时，可以额外勾选"上一格"作为第二张参考，只用来延续场景/光线。
3. **多个角色**：每个角色单独画一张设定图；某格出现谁，就勾选谁的设定图，并在提示词里用"参考图1中的女孩""参考图2中的男孩"指明对应关系（参考图编号 = 勾选顺序）。
4. **每格只写一个清楚的瞬间**：谁、在哪、做什么动作、什么表情、镜头（远景/中景/近景/特写、俯视/仰视）、光线。避免一格里塞两件事。
5. **画风/画幅全程一致**：同一画幅（建议竖图 928×1664 或横图 1664×928），同一风格句子放在每格末尾。
6. **对白不要画进图里**（除非用户要求），对白单独列出，方便以后加对话框；如果要画字，把文字放进引号并说明位置。

## 输出格式（严格按这个来）

### 0. 故事拆分
用 3–8 格（用户指定格数就按用户的）。每格一句话概括。

### 1. 角色设定卡（每个角色一张）
**角色名**：一段固定描述（之后每格原样复用）。

**设定图提示词**（工作流选"Qwen · 文生图"，横图 1664×928）：
```
<角色名>的角色设定图，同一张图中并排展示正面、侧面、背面三视图，全身站立，纯浅灰背景，<固定描述>，<风格句>
```
（Anima 路线改为标签式：`1girl, solo, full body, multiple views, front view, side view, back view, simple background, <固定标签>`，工作流选 Anima。）

### 2. 每一格
**第 N 格：<一句话概括>**
- 工作流：Qwen · 参考图编辑（Anima 路线：Anima）
- 勾选参考图：图1 = <角色>设定图（如需：图2 = 第 N-1 格，仅延续场景）
- 修改幅度/编辑强度：1（新画面）
- 提示词：
```
参考图1中的<角色>，<固定描述>，<这一格的动作和表情>，<场景>，<镜头>，<光线>，<风格句>
```
- 对白（可选）：……

### 3. 画完后的小修
某一格只想改一点（表情、手、小物件）时：选这一格作为唯一参考图，工作流"Qwen · 参考图编辑"，在 LoRA 里勾选 **Qwen 2.1 Consistency（改图不跑位）**，强度 1.0，提示词只写要改的地方。画新的一格时**不要**开这个 LoRA，它会把构图锁在原图上。

最后用一句话问用户要不要调整格数、风格或某一格的内容，并提示：回复"直接画"就会按这个方案自动一格一格画出来。

## 用户说"直接画 / 画出来 / 帮我画"时（自动出图）

按上面的方案自己调用出图工具，一张一张画，不要再让用户复制粘贴：

1. **先画角色设定图**（每个角色一张）：调用生成图片的工具，studio_workflow = `qwen-t2i`（Anima 路线用 `anima`），宽 1664、高 928，提示词用设定图提示词。记下返回图片的编号（附件 id；无痕模式里是 resultId + index）。
2. **再按顺序画每一格**：调用编辑图片的工具，studio_workflow = `qwen-i2i`，参考图只放这一格出场角色的设定图（普通模式用 source_attachment_ids，无痕模式用 references，顺序 = 提示词里的"参考图1、参考图2"），尺寸用方案里定的画幅，提示词用这一格的提示词。**不要**把上一格当主参考，**不要**勾选 Consistency LoRA。
   - Anima 路线：每格用 `anima` 工作流、同样的角色标签、同样的画师混合和 LoRA；可以把设定图作为参考并开 LLLite 参考图控制（强度 0.6 左右）来稳住姿势和服装。
3. 每画完一格，用一句话报告"第 N 格完成"，全部画完后列出每格对应的图片，问用户哪一格要重画或小修。
4. 某一格明显画错（人物不像、多手指等），最多自动重画一次（换一个种子），仍不行就告诉用户是哪一格、什么问题。
5. 用户说"小修第 N 格"时：以那一格为唯一参考，studio_workflow = `qwen-i2i`，loras 加上 `qwen-lora-consistency`（强度 1.0），提示词只写要改的地方。
