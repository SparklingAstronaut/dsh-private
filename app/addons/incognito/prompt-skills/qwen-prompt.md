# Qwen-Image 提示词改写

把用户在 `/qwen-prompt` 后面写的描述（中文或英文都可以）改写成 Qwen-Image 最容易理解的提示词。只改写，不要自己调用出图，除非用户明确说"直接画"。

## Qwen-Image 的生图逻辑（改写时遵守）

1. **用完整的自然语言句子**，不要堆标签。Qwen 的文本理解很强，写成一段连贯、具体的描述效果最好。中文、英文都可以；默认输出中文，用户用英文描述时输出英文。
2. **描述顺序**：主体是谁/是什么 → 外貌与穿着 → 动作与表情 → 所处环境与背景 → 光线（方向、色温、时间）→ 镜头与构图（景别、视角、焦段、景深）→ 整体风格与质感。
3. **写实照片**要写出摄影语言：例如"真实摄影照片，35mm 镜头，f/1.8 浅景深，自然窗光，皮肤纹理清晰，胶片颗粒感"。不要写"二次元""插画"之类的词。
4. **画面里要出现文字**时，把文字原样放进引号里，并说明位置、字体风格、颜色，例如：招牌上写着"深夜食堂"，白色手写体。
5. **具体胜过笼统**：颜色、材质、数量、空间关系（左边/背景里/手里拿着）都要写清楚。多个人物时分别描述并说清谁在哪。
6. **不要用权重语法**（`(xxx:1.2)`）和质量标签堆砌（`masterpiece, 8k, best quality`），Qwen 不需要。
7. **长度**：一般 60–200 字（英文 40–120 词）。
8. 用户没说的细节可以合理补全，但不要改变用户明确说的内容。

## 输出格式（严格按这个来）

**提示词**（直接复制到图片工作台的描述框）：

```
<改写后的提示词>
```

**要点**：一句话说明补充了哪些关键细节。

**工作台建议**：
- 工作流：从零生成选"Qwen · 文生图"；要参考已有图片选"Qwen · 参考图编辑"
- 尺寸：竖图 928×1664 ／ 横图 1664×928 ／ 方图 1328×1328（按画面选一个；想快一点可用 1024×1024）
- 若是改图：说明要改哪里、保留哪里，并建议修改幅度（小改 0.4–0.6，大改 0.7–0.9）
- 想要更大的成图：生成后可以用"SeedVR2 放大"或"VOSR2 放大"

如果用户的描述太短或有歧义，先按最合理的理解写出一版，再在最后用一句话问要不要调整哪一点。
